# BIOBUZZ field background

`biobuzz-2026-2027.png` is the top-down field diagram from page 23 of FIRST's
2026-2027 BIOBUZZ Event Field Setup Guide V1.0 (September 12, 2026):
https://ftc-resources.firstinspires.org/ftc/archive/2027/field/eventfieldguide

Artwork belongs to FIRST / AndyMark, as credited in the source guide.
The diagram was rendered at 600 DPI and clipped to the square playing surface
(pixel rectangle 824,2315,720,720). It is a visual reference, not a surveyed
coordinate table or collision model. Hives are shown in their initial positions.

BiobuzzField rotates this image counterclockwise so red is at the bottom and blue
at the top, then fits it to Dashboard's 144-inch square. The image is bundled in
the APK; the robot does not need internet access to display it.
